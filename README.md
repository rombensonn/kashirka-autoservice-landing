# Лендинг автосервиса «Каширка»

Одностраничный PHP-лендинг для автосервиса в Домодедово.

## Запуск локально

```powershell
php -S 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000`.

## Заявки

Форма сохраняет заявки в `data/leads.csv`. Папка создается автоматически при первой успешной отправке.

Чтобы дополнительно получать заявки на почту, задайте переменную окружения `LEAD_EMAIL` перед запуском или на хостинге:

```powershell
$env:LEAD_EMAIL="mail@example.com"
php -S 127.0.0.1:8000
```

## SEO

В `index.php` уже добавлены:

- Title и description под автосервис в Домодедово;
- canonical URL от текущего домена;
- Open Graph;
- JSON-LD `AutoRepair` с адресом, телефоном, графиком, рейтингом и каталогом услуг.
